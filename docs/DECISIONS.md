# Принятые решения

Решения, принятые без участия владельца: что выбрано и почему.

| Дата | Решение | Почему |
|---|---|---|
| 2026-10-21 | `exactOptionalPropertyTypes` отключён в Vue-пакетах | `defineProps` типизирует необязательные пропсы без `undefined`; с флагом нельзя передать `:prop="maybeUndefined"` |
| 2026-10-21 | Цвета текста `success`/`warning`/`danger` темнее значений из ТЗ | Значения из ТЗ не проходят контраст WCAG AA (проверяет `tokens.contrast.test.ts`) |
| 2026-10-21 | Axe по Storybook — свой скрипт, а не `@storybook/test-runner` | test-runner 0.26 несовместим со Storybook 10.6 (`module.register()` в Jest) |
| 2026-10-21 | Версии Vue Router 4 и Pinia 3 (мажоры из ТЗ), а не последние 5/4 | Следуем таблице стека ТЗ; экосистема (vite-ssg, Storybook) проверена на этих мажорах |
| 2026-10-21 | TypeScript 5.9, не 7 | `typescript-eslint` и `vue-tsc` не поддерживают TS 7 |
| 2026-10-21 | Демо-бренд «Гараж 24» (автосервис), услуги: diagnostics, maintenance, brakes, tires | Нужен вымышленный бренд для демо; slug-и обязаны совпадать с `apps/api/services.json` |
| 2026-10-21 | Текст согласия хешируется на бэкенде из `app/data/consent_text.ru.md`; тест на сайте сверяет его со словарём | В схеме `LeadCreate` нет поля с хешем, а хеш должен соответствовать показанному тексту |
