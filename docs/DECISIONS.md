# Принятые решения

Решения, принятые без участия владельца: что выбрано и почему.

| Дата       | Решение                                                                                                                                    | Почему                                                                                                                             |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10-21 | `exactOptionalPropertyTypes` отключён в Vue-пакетах                                                                                        | `defineProps` типизирует необязательные пропсы без `undefined`; с флагом нельзя передать `:prop="maybeUndefined"`                  |
| 2026-10-21 | Цвета текста `success`/`warning`/`danger` темнее значений из ТЗ                                                                            | Значения из ТЗ не проходят контраст WCAG AA (проверяет `tokens.contrast.test.ts`)                                                  |
| 2026-10-21 | Axe по Storybook — свой скрипт, а не `@storybook/test-runner`                                                                              | test-runner 0.26 несовместим со Storybook 10.6 (`module.register()` в Jest)                                                        |
| 2026-10-21 | Версии Vue Router 4 и Pinia 3 (мажоры из ТЗ), а не последние 5/4                                                                           | Следуем таблице стека ТЗ; экосистема (vite-ssg, Storybook) проверена на этих мажорах                                               |
| 2026-10-21 | TypeScript 5.9, не 7                                                                                                                       | `typescript-eslint` и `vue-tsc` не поддерживают TS 7                                                                               |
| 2026-10-21 | Демо-бренд «Гараж 24» (автосервис), услуги: diagnostics, maintenance, brakes, tires                                                        | Нужен вымышленный бренд для демо; slug-и обязаны совпадать с `apps/api/services.json`                                              |
| 2026-10-21 | Текст согласия хешируется на бэкенде из `app/data/consent_text.ru.md`; тест на сайте сверяет его со словарём                               | В схеме `LeadCreate` нет поля с хешем, а хеш должен соответствовать показанному тексту                                             |
| 2026-10-21 | В layout-компонентах UI вместо инлайновых стилей — классы (gap, колонки Grid, padding)                                                     | Строгий CSP `style-src 'self'` из ТЗ-1 §15 блокирует инлайновые `style="..."` в пререндеренном HTML, в том числе пустой `style=""` |
| 2026-10-21 | Оттенок бренда задаётся виртуальным CSS-модулем (`virtual:brand.css`), а не атрибутом `style` на `<html>`                                  | Тот же CSP                                                                                                                         |
| 2026-10-21 | Вставка в PhoneInput обрабатывается через `beforeinput`, а не `paste`                                                                      | Lighthouse «paste-preventing-inputs» штрафует любой слушатель `paste` на поле                                                      |
| 2026-10-21 | Из шрифта Inter подключены только подмножества cyrillic и latin; ₽ берётся из системного шрифта                                            | latin-ext весил 85 КБ и мешал LCP на медленной сети                                                                                |
| 2026-10-21 | Ленивая гидратация секций главной (hydrateOnIdle / hydrateOnVisible, статичные секции не гидратируются), единый CSS, чанки vendor/sections | Уложиться в LCP < 2.5 с и TBT < 200 мс на мобильном профиле Lighthouse                                                             |
| 2026-10-21 | Lighthouse пропускает аудит is-crawlable; robots.txt в демо — `Disallow: /`                                                                | Требование ТЗ-1 §12.5 (демо не индексируется) противоречит SEO = 100; индексируемость проверяется отдельно                         |
| 2026-10-21 | e2e запускаются командой `pnpm e2e` (не входят в `pnpm -r test`); локально `PW_CHANNEL=chrome`                                             | Скачивание браузеров Playwright недоступно в этой среде, используется установленный Chrome                                         |
| 2026-10-21 | Тесты e2e выжидают 3,3 с после гидратации формы перед отправкой                                                                            | Сервер молча отбрасывает заявки быстрее 3 с (honeypot-защита ТЗ-1 §7.4)                                                            |
| 2026-10-21 | Хуки lefthook не установлены автоматически (`pnpm exec lefthook install` — вручную)                                                        | Нужен локальный gitleaks, на Windows его нет; в CI секреты проверяет задача `secrets`                                              |
| 2026-10-21 | Длительность и буфер услуг живут в site.config.ts и попадают в API через services.json (`services[]`), а не в БД                           | Единый источник каталога, дрейф ловит тест config.test.ts; ограничения 5–480 мин кратно 5 и буфер 0–120 валидирует zod             |
| 2026-10-21 | В миграции 0002 CHECK-ограничения создаются с короткими именами                                                                            | naming convention сам добавляет префикс ck_<table>_, полное имя дублировало бы его                                                 |
| 2026-10-21 | В `bookings` поля `phone_source` и `source` — NOT NULL (в ТЗ только CHECK in)                                                              | Происхождение записи и телефона нужно всегда; значение по умолчанию скрыло бы ошибки сервиса                                       |
