## MAX: проверка телефона requestContact

Документация (dev.max.ru/docs/webapps/bridge) описывает `HMAC_SHA256(authDate + phone + userId, botToken)`, но не уточняет формат результата (hex/base64), источник `userId` (предположительно `initData.user.id`) и не даёт примера. В коде принят hex и пары `key=value` через перевод строки; при несовпадении телефон считается введённым вручную. Нужно проверить на реальном боте, когда будет токен.

## Пользовательское соглашение

В `bootstrap` поле `legal.terms_url` пока `null`: отдельного текста пользовательского соглашения в проекте нет. Нужен текст от владельца.

## MAX: сертификат Минцифры и проверка на реальном боте

Корневой сертификат НУЦ Минцифры должен попасть в образ API при сборке (P10): код поддерживает `MAX_CA_BUNDLE` (путь к PEM), проверка TLS не отключается. Отпечаток сертификата нужно сверить с официальным источником при деплое. Поведение отправки пользователю, не запускавшему бота, и работа `max-subscribe`/`max-check` проверены только на имитации Bot API: нужен токен бота для проверки на реальном MAX.

## WebKit: сообщение CSP на `<select>`

В e2e (WebKit, GitHub Actions) при загрузке формы заявки приходит `style-src-attr` на `<select name="serviceSlug">` (sample пустой). Причину в нашем коде не нашли: стили через CSSOM и `setAttribute('style')` не пишутся. Нужна проверка на живом Safari или Playwright-образе (локально WebKit не ставится на этой машине). Пока такие сообщения игнорируются в тесте; на пользователей это не влияет (в консоли предупреждение, внешнего вида не меняет).

## Мини-приложение: проверить на реальном MAX

- **Календарь:** «Добавить в календарь» передаёт в `WebApp.downloadFile` blob-ссылку (файл запрашивается с initData). Если клиент MAX не примет blob, нужен вариант с временной подписанной ссылкой на `calendar.ics`.
- **Ссылка на бота:** в `apps/max-app/max.config.ts` `botLink` сейчас заглушка (`https://max.ru/id0000000000_bot`): подставить имя бота; оно же — `max.botUsername` в конфиге сайта.
- **Параметр запуска:** `?startapp=s_<slug>` предполагает, что MAX передаёт `start_param` в `initDataUnsafe`; сверить на реальном клиенте.
- **frame-ancestors:** начальное значение `'self' https://*.max.ru`, сверить на веб-версии и desktop-клиенте и сузить (ТЗ-2 §10.2).
- **Системная кнопка «Назад»:** поведение `BackButton.onClick/offClick` проверено только на имитации.
